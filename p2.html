The controller only controls what the sensor says

In P1 the controller saw the true output instantly. Real sensors are slow, as Homework 1 showed: a sensor with time constant τs reports a delayed, smoothed copy of the output. The controller cannot see the true output, only the sensor reading ym(t), so it reacts late. As τs grows, the overshoot grows until the loop oscillates.
