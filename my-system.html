1. Project Application

The Shams Micromouse robot uses drive motors to control wheel motion. This application investigates how a PID controller can track a desired motor speed using encoder feedback.

3. PID Controller Design

Adjust the gains to control the motor speed. The initial PI gains are selected to give an ideal linear-model damping ratio of about 0.707 for K = 1 and τ = 0.25 s.

Theoretical PI model: With Kd = 0 and without saturation or sensor delay, the closed-loop denominator is:

τs² + (1 + KKp)s + KKi

The estimated damping ratio for the ideal continuous PI model is:

ζ = (1 + KKp) / (2√(τKKi))

6. Design Specification

For the Micromouse speed loop, a practical damping-ratio objective from the lecture is:

0.6 ≤ ζ ≤ 0.8

The normalized PWM command must stay between 0 and 1, corresponding to 0–100%. Additional preliminary performance targets are used to evaluate the simulated response.

The damping-ratio calculation applies only to the unsaturated, continuous-time PI model with negligible sensor delay. The other checks use the numerical response. These are simulation checks, not proof of real motor performance.
